# กระดิ่งแจ้งเตือนในแอป (รอบ AL)

กล่องแจ้งเตือนในแอป แยกจากคิวข้อความ `db.outbox` (FB/SMS/Telegram) — **ทำงานเสมอ แม้กฎ/ช่องทางภายนอกปิด** · ไม่มี toast/เสียง · ข้อมูลอยู่ในหน่วยความจำ (จำลอง) จนกว่าจะต่อ Supabase

- ฝั่งหลังบ้าน: กระดิ่งในแถบบน (ทุกขนาดจอ) · ฝั่งหน้าร้าน: เฉพาะลูกค้าที่ล็อกอิน · ปุ่ม `components/BellMenu.vue` (prop `audience`) มีป้ายตัวเลข (99+), แผงรายการเลื่อนได้ (มือถือ `fixed inset-x-2`, จอใหญ่ popover ชิดขวา), "อ่านทั้งหมด", กดรายการ = ทำเครื่องหมายอ่าน + ไปหน้าที่เกี่ยวข้อง · ปิดด้วย Esc/คลิกนอก
- `lib/bell.js` (ฟังก์ชันล้วน): ตารางเหตุการณ์ `BELL_STAFF` (สิทธิ์ที่เห็น/ลิงก์/สี) + `BELL_CUSTOMER`, `bellText`, `visibleToStaff`, `unreadStaff`, `unreadCustomer`, `relTime`
- `store.js`: `db.bell` (ใหม่สุดก่อน ≤ 200) · `emitBell()` เรียกที่ต้น `notify()` ครอบทุกจุดเดิม · แชทใหม่ (`receiveMessage`), บอทส่งต่อ, คำขอลบข้อมูล ส่งตรง · API: `bellFeed(aud)`, `bellUnreadCount(aud)`, `bellMarkRead(id, aud)`, `bellMarkAll(aud)`

## กติกา
- อ่านแล้วแยกรายผู้ใช้ (`readBy` = userId) · ของลูกค้า `read` · ลูกค้าเห็นเฉพาะ `customerId` ตนเอง
- แชทเดียวกันที่ยังไม่มีใครอ่าน ยุบเป็นรายการเดียว (นับ +N) · แชทที่อ่านแล้วมีข้อความใหม่ = รายการใหม่
- ติ๊ก "ไม่แจ้งลูกค้า" → ไม่มีรายการฝั่งลูกค้า (ฝั่งพนักงานยังขึ้น) · บิล POS แจ้งตามปกติ · อวยพรวันเกิดไม่ขึ้น · คะแนนใกล้หมดอายุเคารพ `promoOptIn`
- ไม่แสดง: ยืนยันชำระ/ยกเลิก ฝั่งพนักงาน (ไม่ได้เลือก)
- demo: รายการเก่ากว่า 1 วันถือว่าอ่านแล้ว
