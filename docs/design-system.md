# ดีไซน์ระบบ (Sweet Bakery)

ธีมอยู่ที่ `src/style.css` (`@theme`) จุดเดียว — หน้าร้านและหลังบ้านใช้ token ชุดเดียวกัน

- **สี**: `brand-*` ชมพูสตรอว์เบอร์รี (500 `#ff5e7e` = สีไกด์, 600 `#d43760` = พื้นปุ่มหลักให้ตัวขาวอ่านได้ ≥4.5:1) · `stone-*` น้ำตาลช็อกโกแลตอุ่น (800 `#3f2e2e`) · เสริม `peach #ff9d5b`, `honey #ffd05c`, `matcha #8ed1a8` (`matcha-soft`), `choco`, พื้น `cream #fff8f2` · ไล่เฉดแบนเนอร์ `hero-1..3` · สีสถานะ (emerald/rose/amber) คงเดิม
- **ฟอนต์**: เนื้อหา/หลังบ้าน = Prompt (400/500/600/700) · หัวข้อ/ปุ่มหน้าร้าน = Mitr (`font-display` 400/500/600) — ฝังมากับเว็บ (`src/fonts.css` อ้างไฟล์ woff2 จาก `@fontsource/prompt` และ `@fontsource/mitr` เฉพาะชุดอักษรไทย + ละติน) ไม่โหลดจาก Google Fonts · เพิ่มน้ำหนักใหม่ต้องเพิ่ม `@font-face` ใน `src/fonts.css` ด้วย
- **คลาส**: `.btn-primary` ชมพู · `.btn-soft` · `.btn-outline` · `.btn-peach` (ส้ม) · `.btn-matcha` (มัทฉะ เช่นปุ่มเข้าสู่ระบบ) · ครอบด้วย `.store-theme` (`StoreLayout.vue`) ปุ่มจะมนเต็มและใช้ฟอนต์หัวข้อ; หลังบ้านคงปุ่มมนเล็กเพื่อไม่เปลี่ยนเลย์เอาต์
- **ภาพประกอบ** (`src/components/art/`): `CakeArt` (ภาพวาดเค้กเลือกตามชื่อสินค้า `lib/cakeArt.js`) ใช้เป็น placeholder ใน `CakeImage` เมื่อยังไม่มีรูปจริง (รูปที่ร้านอัปโหลดจะแทนที่เอง) · `HeroCake` · `StepArt` (ไอคอนวิธีสั่งซื้อ) · `Bunting` (ธงราว) · `Doodles` (ลายเส้นตกแต่ง)
- **หน้าแรกร้าน** (`StoreHome.vue`): แบนเนอร์ → โปรโมชั่น → สินค้าขายดี (ป้าย "ยอดฮิต") → เค้กสั่งทำ → ผลงาน/รีวิว (ถ้ามี) → วิธีสั่งซื้อ (timeline) → FAQ/นโยบาย 2 คอลัมน์ → ติดต่อ · ฟุตเตอร์ช็อกโกแลต · แถบคุกกี้มัทฉะ (ยอมรับทั้งหมด / ปฏิเสธ = ใช้เฉพาะที่จำเป็น / ตั้งค่า)
- ใบเสร็จ 80mm และใบกำกับ A4 ยังพิมพ์ขาวดำตามกฎ `@media print` เดิม

## รอบ Y: หน้าที่เหลือ
- **คลาสร่วม** (`style.css`): `.seg-grid` (แท็บ segmented มนเต็ม ใช้กับ `grid-cols-N` เดิมทั้ง 31 จุด) · `.seg` / `.seg-item` / `.seg-on` (ใช้ในหน้าร้าน: เมนู, บัญชี, แต้มสะสม, ตัวตั้งค่าเค้กสั่งทำ) · `.empty` (สถานะว่างการ์ดมนขอบประ) · `.store-theme .card` มนมากเงานุ่ม · `h1/h2` ทั้งระบบใช้ Mitr
- **สีสถานะออเดอร์** (`lib/constants.js` `STATUS`): โทนพาสเทล (พื้น -100 ตัวอักษร -700/-800) ตรวจ contrast ≥4.5:1 · ยืนยันชำระ = ชมพูแบรนด์ · ป้ายมีตัวอักษร+จุดเสมอ (ไม่พึ่งสีอย่างเดียว) · `PayDueBadge`/ป้ายชำระใช้โทนเดียวกัน
- **หน้าร้านที่ปรับ**: เมนู, หน้าสินค้า/เค้กสั่งทำ (`StoreItem`, `CakeConfigurator`, `ItemCard`), หน้าออเดอร์ลูกค้า/ลิงก์ (`CustomerOrderView`), ล็อกอิน/สมัคร (ภาพวาดหัวฟอร์ม + ตัวบอกขั้น)/ลืม PIN, บัญชี + แต้มสะสม (ฮีโร่ไล่เฉดชมพู-แดงเหมือนแบนเนอร์)
- **หลังบ้านที่ปรับลึก**: หัว/แถบล่างมือถือ/โมดัล (`AppModal`)/หัวหน้า (`ManageShell`, `Accounting`) · หน้าจัดการ (ไอคอนวงกลมพาสเทลหมุนสี) · รายการออเดอร์ (การ์ดมน) · POS (ไทล์มน เลือก = ชมพูอ่อน) · กราฟยอดขาย/กำไร (ชมพู + เขียว #4a9d73) — หน้าอื่นเปลี่ยนตามชิ้นส่วนร่วม

## เลย์เอาต์หลังบ้านบน PC (รอบ AD)
- **แถบแท็บ/ชิปที่ล้น**: มือถือเลื่อนแนวนอนได้ (ซ่อนแถบเลื่อน) · md ขึ้นไปให้ **ห่อขึ้นบรรทัดใหม่** (`md:flex-wrap md:overflow-visible`) ห้ามปล่อยให้ตัดขอบโดยไม่มีทางเลื่อน (ใช้กับแท็บบัญชี และแท็บย่อยรายงาน)
- **แถบปุ่มล่าง `.action-bar`**: `fixed` ใช้เฉพาะมือถือ · md ขึ้นไปต้อง `md:static md:mt-4 md:border-0 md:bg-transparent md:p-0 md:backdrop-blur-none` ไม่ลอยทับเนื้อหา (สร้างออร์เดอร์ใช้ md, รายละเอียดออร์เดอร์ใช้ lg)
- **แชท**: กล่อง grid สูงคงที่ต้องมี `grid-rows-[minmax(0,1fr)]` และคอลัมน์ `minmax(0,1fr)` + `min-w-0` เพื่อไม่ให้เนื้อหา (แถบปุ่ม/ข้อความยาว) ดันช่องพิมพ์/ปุ่มส่งออกนอกจอ
- **ช่องวันที่/เวลาของโปร (ScheduleEditor)**: ใช้ `ThaiDateField` (วัน · เดือน · ปี พ.ศ.) และ `ThaiTimeField` (24 ชม.) แทน `input type=date/time` ที่แสดง mm/dd/yyyy ตามภาษาเบราว์เซอร์ · ค่าที่เก็บเหมือนเดิม (`YYYY-MM-DD`, `HH:MM`) · ช่องวันที่ native ที่อื่นยังไม่เปลี่ยน

## ป๊อปอัป (รอบ AE)
- **ห้ามใช้ `dvh`/`vh` กำหนดความสูงกล่องป๊อปอัป** (บางเครื่อง/สเกลจอคำนวณใหญ่กว่าพื้นที่จริง → กล่องเลยขอบ เลื่อนไม่ได้)
- โครง: overlay `fixed inset-0 overflow-y-auto overscroll-contain` → ตัวห่อ `flex h-full items-end sm:items-center sm:p-6` (คลิกพื้นหลังปิด) → กล่อง `max-h-full min-h-0 flex flex-col overflow-hidden` · หัว/ปุ่มท้าย `shrink-0` ติดตลอด เนื้อหากลาง `min-h-0 flex-1 overflow-y-auto`
- ใช้ใน `AppModal`, `ConfirmDialog`, ตารางอัตราภาษีใน `AcctTaxYear` · ป๊อปอัปใหม่ให้ใช้ `AppModal`

## เลเอาท์ PC เต็มพื้นที่ (รอบ AF)
- **โทเคนความกว้าง**: `--container-page: 96rem` (1536px) ใน `@theme` → ใช้ `max-w-page` ทั้งหลังบ้านและหน้าร้าน (header/main/footer) · ขอบข้าง `px-4 lg:px-8` · มือถือ/แท็บเล็ตไม่เปลี่ยน
- **หน้ารายการ** (ManageShell ปกติ, ออร์เดอร์, POS, บัญชี, วัตถุดิบ, ตารางผลิต, แชท, รายละเอียดออร์เดอร์) ใช้เต็ม container · การ์ดเพิ่มคอลัมน์ที่ lg/xl/2xl (ManageHome 3→4, รายการจัดการ 2→3, ออร์เดอร์ 2→3, POS สินค้า 3→5 + ตะกร้า 360→420, กริดหน้าร้าน/แกลเลอรี 4→5→6)
- **หน้าฟอร์ม/ตั้งค่า**: `<ManageShell narrow>` จำกัด `max-w-4xl` (ร้าน, หน้าร้าน, PDPA, คะแนน, ลิงก์, บอท, การเชื่อมต่อ, ราคา, กลุ่มตัวเลือก) · ช่องค้นหา `input[type=search].input` จำกัด 40rem บน lg+ · ห้ามให้ช่องกรอกเดี่ยวยืดเกิน ~900px
- **สร้างออร์เดอร์** (PC lg+): ฟอร์มซ้าย `max-w-3xl` + แผงสรุปขวา (22rem/26rem, ติด `sticky`) ขั้น 1–3 · ขั้นสรุปไม่มีแผง · โหมดฝังในแชทไม่เปลี่ยน
- หน้าสินค้าเดี่ยว (`StoreItem`, `StoreCakeDesign`) `max-w-6xl` · หน้าข้อความ/บัญชีลูกค้า `max-w-2xl` ไม่ขยาย
- โหลดเพิ่มอัตโนมัติ (แกลเลอรี, แบบแนะนำ) ทำงานหลังลูกค้าเลื่อน/กดแล้วเท่านั้น (จอกว้างไม่โหลดเกิน 10/4 รายการแรกเอง)

## รายการสินค้าในหน้ารายละเอียดออร์เดอร์ (รอบ AJ)
แต่ละชิ้น = กรอบเดียว `rounded-2xl border border-stone-300 border-l-[6px] bg-white` (แถบซ้าย: เค้กสั่งทำ `brand-500` · สินค้าสำเร็จ `amber-500` · ของแถม `emerald-600`) มีวงกลมเลขลำดับ `#N` (`ItemCard` prop `index`, `bare` = ไม่วาดการ์ดซ้อน) · ปุ่มแก้ไข/ลบและรูปงานอยู่ในกรอบเดียวกัน (รูปงานแยกด้วยเส้น `border-t` พื้น `stone-50`) · เว้นระหว่างชิ้น `space-y-4`

## การโหลดหน้าเว็บ (รอบ AK)
- **ฟอนต์ฝังมากับเว็บ**: ไม่มีสไตล์ชีตข้ามโดเมนที่บล็อกการวาดหน้า และไม่ต้องเปิดการเชื่อมต่อไป Google 2 โดเมน
- **เปิดหน้าไม่รอไลบรารี Supabase**: `initStaff()` ข้ามการตรวจเซสชันเมื่อเบราว์เซอร์ไม่มีคีย์เซสชันพนักงาน (`lib/staffSessionHint.js`) → ผู้เยี่ยมชมหน้าร้านเห็นหน้าเว็บได้เลย ข้อมูลร้านโหลดต่อเบื้องหลัง
- **วาดแอปหลังเส้นทางแรกพร้อม** (`main.js` รอ `router.isReady()`): เดิมแอปวาดโครงหลังบ้าน (แถบบน) แวบหนึ่งก่อนสลับเป็นหน้าร้าน/หน้าล็อกอิน ตอนนี้ค้างที่ข้อความ "กำลังเตรียมข้อมูล…" จนโครงที่ถูกต้องพร้อม
- **แคช** (`public/_headers`): `/assets/*` (ไฟล์มี hash) `Cache-Control: public, max-age=31536000, immutable` → เปิดซ้ำไม่ดาวน์โหลด/ไม่ถามเซิร์ฟเวอร์ซ้ำ · `index.html` ยังตรวจใหม่ทุกครั้ง
- **preconnect** ไปยัง Supabase / Worker ไฟล์ ใส่ตอน build จากตัวแปร `VITE_*` (`vite.config.js` `preconnectHints`) · ไม่ใช้ preload ชุดโค้ด/ฟอนต์ (วัดบนเครือข่ายช้าแล้วหน้าแรกขึ้นช้าลง)
- ผลวัด (เครือข่ายจำลอง 1.6 Mbps / 150 ms, CPU ช้า 4 เท่า, ข้อมูลจำลอง): เนื้อหาหลักหน้าแรก (LCP) 2.6 → 1.9 วินาที · หน้าเมนู 2.3 → 1.9 วินาที
