# ดีไซน์ระบบ (Sweet Bakery)

ธีมอยู่ที่ `src/style.css` (`@theme`) จุดเดียว — หน้าร้านและหลังบ้านใช้ token ชุดเดียวกัน

- **สี**: `brand-*` ชมพูสตรอว์เบอร์รี (500 `#ff5e7e` = สีไกด์, 600 `#d43760` = พื้นปุ่มหลักให้ตัวขาวอ่านได้ ≥4.5:1) · `stone-*` น้ำตาลช็อกโกแลตอุ่น (800 `#3f2e2e`) · เสริม `peach #ff9d5b`, `honey #ffd05c`, `matcha #8ed1a8` (`matcha-soft`), `choco`, พื้น `cream #fff8f2` · ไล่เฉดแบนเนอร์ `hero-1..3` · สีสถานะ (emerald/rose/amber) คงเดิม
- **ฟอนต์**: เนื้อหา/หลังบ้าน = Prompt · หัวข้อ/ปุ่มหน้าร้าน = Mitr (`font-display`) — โหลดจาก Google Fonts ใน `index.html`
- **คลาส**: `.btn-primary` ชมพู · `.btn-soft` · `.btn-outline` · `.btn-peach` (ส้ม) · `.btn-matcha` (มัทฉะ เช่นปุ่มเข้าสู่ระบบ) · ครอบด้วย `.store-theme` (`StoreLayout.vue`) ปุ่มจะมนเต็มและใช้ฟอนต์หัวข้อ; หลังบ้านคงปุ่มมนเล็กเพื่อไม่เปลี่ยนเลย์เอาต์
- **ภาพประกอบ** (`src/components/art/`): `CakeArt` (ภาพวาดเค้กเลือกตามชื่อสินค้า `lib/cakeArt.js`) ใช้เป็น placeholder ใน `CakeImage` เมื่อยังไม่มีรูปจริง (รูปที่ร้านอัปโหลดจะแทนที่เอง) · `HeroCake` · `StepArt` (ไอคอนวิธีสั่งซื้อ) · `Bunting` (ธงราว) · `Doodles` (ลายเส้นตกแต่ง)
- **หน้าแรกร้าน** (`StoreHome.vue`): แบนเนอร์ → โปรโมชั่น → สินค้าขายดี (ป้าย "ยอดฮิต") → เค้กสั่งทำ → ผลงาน/รีวิว (ถ้ามี) → วิธีสั่งซื้อ (timeline) → FAQ/นโยบาย 2 คอลัมน์ → ติดต่อ · ฟุตเตอร์ช็อกโกแลต · แถบคุกกี้มัทฉะ (ยอมรับทั้งหมด / ปฏิเสธ = ใช้เฉพาะที่จำเป็น / ตั้งค่า)
- ใบเสร็จ 80mm และใบกำกับ A4 ยังพิมพ์ขาวดำตามกฎ `@media print` เดิม

## รอบ Y: หน้าที่เหลือ
- **คลาสร่วม** (`style.css`): `.seg-grid` (แท็บ segmented มนเต็ม ใช้กับ `grid-cols-N` เดิมทั้ง 31 จุด) · `.seg` / `.seg-item` / `.seg-on` (ใช้ในหน้าร้าน: เมนู, บัญชี, แต้มสะสม, ตัวตั้งค่าเค้กสั่งทำ) · `.empty` (สถานะว่างการ์ดมนขอบประ) · `.store-theme .card` มนมากเงานุ่ม · `h1/h2` ทั้งระบบใช้ Mitr
- **สีสถานะออเดอร์** (`lib/constants.js` `STATUS`): โทนพาสเทล (พื้น -100 ตัวอักษร -700/-800) ตรวจ contrast ≥4.5:1 · ยืนยันชำระ = ชมพูแบรนด์ · ป้ายมีตัวอักษร+จุดเสมอ (ไม่พึ่งสีอย่างเดียว) · `PayDueBadge`/ป้ายชำระใช้โทนเดียวกัน
- **หน้าร้านที่ปรับ**: เมนู, หน้าสินค้า/เค้กสั่งทำ (`StoreItem`, `CakeConfigurator`, `ItemCard`), หน้าออเดอร์ลูกค้า/ลิงก์ (`CustomerOrderView`), ล็อกอิน/สมัคร (ภาพวาดหัวฟอร์ม + ตัวบอกขั้น)/ลืม PIN, บัญชี + แต้มสะสม (ฮีโร่ไล่เฉดชมพู-แดงเหมือนแบนเนอร์)
- **หลังบ้านที่ปรับลึก**: หัว/แถบล่างมือถือ/โมดัล (`AppModal`)/หัวหน้า (`ManageShell`, `Accounting`) · หน้าจัดการ (ไอคอนวงกลมพาสเทลหมุนสี) · รายการออเดอร์ (การ์ดมน) · POS (ไทล์มน เลือก = ชมพูอ่อน) · กราฟยอดขาย/กำไร (ชมพู + เขียว #4a9d73) — หน้าอื่นเปลี่ยนตามชิ้นส่วนร่วม
