# สิทธิ์ใช้งานแบบติ๊ก (รอบ L · พนักงานเท่านั้น ไม่เกี่ยวกับบัญชีลูกค้า)

- ผู้ใช้แต่ละคนมี `perms` (รายการสิทธิ์ที่ติ๊ก) · บทบาท (แอดมิน/ขาย/คนทำเค้ก/คนส่ง) เป็นค่าตั้งต้น (`PERMISSIONS` → `rolePreset`) กด "ใช้ค่าตั้งต้นของ…" เพื่อรีเซ็ต · สิทธิ์เดิมของแต่ละบทบาทไม่เปลี่ยน
- จัดการที่ จัดการ → ผู้ใช้ & สิทธิ์ (ต้องมี `manageUsers`): ติ๊กรายข้อ/ทั้งกลุ่ม ค้นหาสิทธิ์ได้ · มีประวัติแก้สิทธิ์ (`db.permLog`)
- กันล็อกตัวเอง: ต้องเหลือผู้ใช้ที่ใช้งานอยู่และมี `manageUsers` อย่างน้อย 1 คนเสมอ · ถอดสิทธิ์ของตัวเองต้องยืนยัน
- `can(action)` ใช้ `perms` ของผู้ใช้ปัจจุบัน (`session.userId`) · "ทดลองใช้งานเป็น" สลับผู้ใช้ (ยังไม่มีล็อกอินจริง) · ผู้ใช้ที่ปิดใช้งานไม่มีสิทธิ์
- การเห็นรายการออร์เดอร์: `viewAllOrders` / `viewPrepOrders` (ยืนยันชำระ→เตรียมแล้ว) / `viewDeliveryOrders` (จัดส่ง) แทน `VISIBLE` รายบทบาท
- เส้นทางหลังบ้านตรวจสิทธิ์ (router `meta.perms`) ไม่มีสิทธิ์ → หน้า "ไม่มีสิทธิ์" · หน้าจัดการตรวจใน `ManageShell` (`perm`)
- สิทธิ์ของระบบบัญชีเตรียมไว้แล้ว: `acctView acctRecord acctClose acctReports acctTax acctAssets taxInvoice acctSettings`
