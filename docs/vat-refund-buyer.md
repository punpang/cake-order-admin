# VAT · คืนเงินตอนยกเลิก · เปลี่ยนผู้ซื้อ (รอบ C)

## VAT
- ตั้งค่าที่ `/admin/settings/shop`: เปิด/ปิด · อัตรา % · **VAT ใน** (ราคาที่ตั้งรวม VAT แล้ว ยอดที่ลูกค้าจ่ายไม่เปลี่ยน แยกแสดงบรรทัด VAT = ยอด × r ÷ (100 + r)) หรือ **VAT นอก** (บวกเพิ่มท้ายยอด = ยอด × r ÷ 100) · ชื่อ/เลขประจำตัวผู้เสียภาษี (แสดงบนใบเสร็จ)
- ฐานภาษี = สินค้า + ค่าส่ง **หลังส่วนลดทุกประเภท** (ส่วนลดรายสินค้า โปร บันเดิ้ล ปรับราคา คะแนนที่ใช้ คูปอง) ปัดสตางค์ 2 ตำแหน่ง · ฐานติดลบ = ไม่มี VAT
- เก็บ snapshot `order.vat = { rate, mode }` ตอนสร้างออร์เดอร์/บิล POS/ใบเสนอ → แก้ตั้งค่าภายหลังไม่กระทบออร์เดอร์เดิม (ไม่มี `vat` = ไม่คิด) · ออร์เดอร์จากใบเสนอใช้ VAT ตามใบเสนอ
- `orderTotals`: `vat`, `vatAdd` (เฉพาะแบบนอก), `vatRate`, `vatMode`, `beforeVat` (= total − vat ใช้เป็นรายได้/กำไร), `fullAll` (ราคาเต็มรวมค่าส่ง/VAT ใช้กับป้ายส่วนลด) · `total` = ยอดที่ลูกค้าต้องจ่าย · ยอดขาย/กำไรในหน้ายอดขายและรายละเอียดออร์เดอร์นับ **ก่อน VAT**
- คะแนนสะสมคิดจากราคาสินค้าที่แสดง (แบบ VAT ใน ราคารวม VAT แล้ว) ไม่รวมค่าส่ง และไม่รวม VAT แบบนอก
- ใบเสร็จของระบบนี้ **ไม่ใช่ใบกำกับภาษีเต็มรูป** (ไม่มีข้อมูลผู้ซื้อ/เลขที่ใบกำกับ) ถ้าต้องออกใบกำกับภาษี ให้ปรึกษานักบัญชีและทำเป็นงานแยก

## คืนเงินตอนยกเลิก (ออร์เดอร์ + บิล POS)
- `cancelOrder(order, { reason, refunds: [{ method: cash | transfer | points, amount }], refundNote })` แบ่งหลายช่องทางได้ รวมไม่เกินยอดที่ยืนยันชำระแล้ว · ตรวจก่อนแก้ข้อมูลทุกอย่าง คืน `{ ok }` หรือ `{ error }` (ไม่ผ่าน = ไม่เปลี่ยนอะไร รวมถึงสต็อก POS)
- คืนเป็นคะแนน: ต้องมีลูกค้า · ยอด ÷ มูลค่าต่อคะแนน ต้องลงตัว (ไม่ปัดทิ้งเงิน) · ได้ก้อนคะแนนใหม่ อายุตามค่าตั้งต้น (`pointExpireDays`) · แยกจากคะแนนที่ถูกตัดคืนเพราะยกเลิก (คะแนนที่ได้จากออร์เดอร์นั้น + คะแนน/คูปองที่ใช้ ถูกคืน/ตัดตามเดิม)
- รูปแบบเก่า `{ refundAmount, refundMethod }` ยังรับได้ · `order.cancel` เก็บ `refunds`, `refundAmount` (รวม), `refundMethod` (ข้อความสรุป) · ลูกค้าเห็นช่องทางที่คืนในหน้าบัญชี
- ค่าตั้งต้นของ UI = คืนเต็มตามช่องทางที่ลูกค้าจ่าย (เงินสด → เงินสด · อื่น ๆ → ธนาคาร)

## เปลี่ยนผู้ซื้อ (แอดมิน + พนักงานขาย `changeBuyer`)
- ได้ทุกสถานะที่ยังไม่ยกเลิก (รวมส่งมอบแล้วและบิล POS) · ผู้ซื้อใหม่ต้องมีเบอร์โทร ไม่ใช่ลูกค้าที่ลบแล้ว
- ส่วนลดจากคะแนน/คูปองที่ใช้ในออร์เดอร์ **ถูกนำออก** และคืนผู้ซื้อเดิม → ยอดรวมเพิ่ม (ดูผลก่อนยืนยัน) · ถ้าส่งมอบแล้ว ยอดคงค้างอาจเกิดขึ้น
- ส่งมอบแล้ว: โอนคะแนนที่ได้ + สิทธิ์หมุนจากผู้ซื้อเดิมไปผู้ซื้อใหม่ (ตัดจากเดิมเท่าที่เหลือ ไม่ติดลบ ผู้ซื้อใหม่ได้เต็ม) · บิลที่ไม่เคยมีสมาชิกแล้วใส่สมาชิกภายหลัง = ให้คะแนนตามยอดสุทธิ
- ถ้าออร์เดอร์ผูกกับแชทของผู้ซื้อเดิม จะตัดการผูกแชท · บันทึกประวัติ
