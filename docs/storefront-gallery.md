# เมนูหน้าเว็บ: เค้กสั่งทำ + คลังรูป + สินค้าตามหมวด

- **เค้กสั่งทำ = การ์ดเดียว** ในเมนู → หน้า `/menu/custom` ลูกค้าเลือกประเภทในหน้าเดียว แล้วเลือกเนื้อ/ขนาด/ตกแต่ง (ตัวคิดราคาเดิม) · `/menu/custom/:id` ยังใช้ได้ (เลือกประเภทนั้นไว้ก่อน)
- **คลังรูปติดแท็ก** (จัดการ → คลังรูปเค้กสั่งทำ): ติ๊กตัวเลือกที่รูปเป็นตัวแทน (ประเภท/เนื้อ/ขนาด/ตกแต่ง…) แล้วอัปโหลดหลายรูปทีเดียว (แท็กชุดเดียวกัน) · แผงความครอบคลุมบอกตัวเลือก/แบบที่ลูกค้าสั่งจริงแต่ยังไม่มีรูป · รูปหน้าปกประเภทเดิมนับเป็นรูปแท็กประเภท
- **เลือกรูป** (`lib/cakeImage.js`): คะแนน = Σ น้ำหนักแท็กที่ตรง (ประเภท 8 · เนื้อ 4 · ขนาด 2 · อื่น 1) − 0.6 × น้ำหนักแท็กที่ไม่ตรง · ไม่ตรงเป๊ะ → ใช้รูปใกล้เคียงสุดพร้อมข้อความ "รูปตัวอย่างใกล้เคียง (ตรงกับ… ยังไม่มีรูปของ…)" · คะแนนเท่ากันหลายรูป → แถบภาพย่อสลับ
- **สินค้าจาก POS แยกหมวด**: แสดงทุกหมวดเป็นส่วน (ชิปกระโดดไปหมวด) ป้ายหมด/เหลือน้อย ตัวเลือกเสริมเหมือน POS · เงื่อนไขแสดงตามเดิม (เปิดใช้งาน + แสดงที่หน้าร้านเว็บ)
- รูปจำลองเก็บในหน่วยความจำ (ของจริง Supabase Storage)
