# ข้อมูลตัวอย่าง (mock data)

`src/data/demo.js` → `seedDemo()` ถูกเรียกจาก `src/main.js` ก่อน mount ทุกครั้งที่เปิดเว็บ (เก็บในหน่วยความจำ รีเฟรชแล้วสร้างใหม่ ~0.1–0.3 วินาที)

## หลักการ
- สร้างผ่านฟังก์ชันจริงของ `store.js` / `acct.js` (createOrder, receivePaymentNow, setStatus, posSale, issueTaxInvoice ฯลฯ) → กติกา/บัญชี/คะแนนสอดคล้องกับระบบจริง
- "ย้อนนาฬิกา" ด้วยการแทน `Date` ชั่วคราว ให้เวลาในประวัติกระจายตลอด ~90 วันที่ผ่านมา (คิดจากวันนี้ ข้อมูลไม่เก่า) แล้วคืนค่าเดิมเสมอ (try/finally) · สุ่มแบบกำหนดเมล็ด ผลเหมือนเดิมทุกครั้ง
- ไม่เปลี่ยน session และไม่ import ใน `store.js` → ชุดทดสอบ node ที่ใช้ store เปล่าไม่กระทบ

## ข้อมูลที่สร้าง
ลูกค้า ~27 · ออร์เดอร์ ~84 (ทุกสถานะ มีนัดอนาคต) + บิล POS ~124 (14 กะ กะวันนี้เปิดอยู่) · รูปงานเสร็จ/แกลเลอรี ~33 + คลิกดูแบบนิรนาม · คะแนน/คูปอง/กาชา · รีวิว 20 · แชท 11 + ใบเสนอ 3 · สินค้าเพิ่ม/วัตถุดิบเพิ่ม/โปรโมชัน (สินค้าโปรหน้าแรก)
บัญชี: ค่าใช้จ่ายประจำ 4 · รายการมือ ~23 · สินทรัพย์ 4 · รับ/จ่ายล่วงหน้า 2 · เงินกู้ 1 (จ่าย 2 งวด) · ใบกำกับภาษี ~9 (มีใบลดหนี้) · VAT ยื่นแล้ว 3 เดือน + ปิดงวดถึงสิ้นเดือนที่แล้ว
ตั้งค่าร้าน: เปิด VAT 7% (ราคารวม VAT) พร้อมข้อมูลผู้ประกอบการตัวอย่าง (เลขภาษีสมมติ)
