# สถานะออร์เดอร์ & กำหนดชำระ (รอบ F)

ลำดับ: ร่าง → รอชำระ → แจ้งยอดแล้ว → (ยืนยันชำระ | ยืนยันการสั่งซื้อ) → กำลังเตรียม → เตรียมสินค้าแล้ว → ส่งมอบแล้ว (ยกเลิกได้ก่อนส่งมอบ)

- **ยืนยันการสั่งซื้อ (ยังไม่ชำระ)**: ใช้เมื่อยังไม่มียอดชำระ แอดมินกดยืนยันตรงได้ พนักงานขายต้อง "ขออนุมัติ" ให้แอดมินอนุมัติ/ไม่อนุมัติ · ส่งมอบยังต้องคงค้าง = 0
- **กำหนดชำระ**: ตอนแจ้งยอดเลือก 15 นาที / 30 นาที / 1 ชม. / 3 ชม. / 24 ชม. / ไม่กำหนด / กำหนดเอง (ค่าเริ่มต้นตั้งที่ ตั้งค่าร้าน → กำหนดชำระเริ่มต้น) · ตัวแปรข้อความ `{ชำระก่อน}` `{ลิงก์ออร์เดอร์}`
- **เลยกำหนด**: ไม่ยกเลิกอัตโนมัติ · แจ้งทีม (Telegram, ครั้งเดียว) · ป้าย "เกินกำหนดชำระ" ในรายการ/รายละเอียด/แชท/บัญชีลูกค้า · ลูกค้าต้องขอขยายเวลา → พนักงานขยายหรือไม่อนุมัติ
- โหมดจำลอง: ข้อมูลอยู่ในหน่วยความจำของเบราว์เซอร์
