# ระบบจัดส่ง (รอบ K)

- ออร์เดอร์จัดส่งเก็บ: ชื่อสถานที่ · ที่อยู่ · url แผนที่ (https เท่านั้น) · รายละเอียด · ระยะทาง (กม.) · ค่าส่ง (ลูกค้าออก)
- ค่าส่งจากระยะทาง (ตั้งค่าร้าน → ค่าจัดส่งจากระยะทาง, ปิดเป็นค่าเริ่มต้น): ≤ ฟรีกี่ กม. = 0 · เกินแล้ว (กม. − ฟรี) × บาท/กม. ปัดขึ้นทีละ N บาท และไม่ต่ำกว่าขั้นต่ำ · พนักงานแก้ทับได้ (ป้าย "แก้ค่าส่งเอง") · ระยะทางกรอกเอง ไม่ต่อ Google Maps
- จำสถานที่ต่อลูกค้าอัตโนมัติ (ที่อยู่+url เดียวกัน = ใช้ซ้ำ, เก็บ 10 ที่ล่าสุด, ไม่เก็บค่าส่ง) · พนักงานเพิ่ม/แก้/ลบ/ขึ้นแรกได้ที่ จัดการ → ลูกค้า · การลบข้อมูลลูกค้าล้างสถานที่และฟิลด์จัดส่งในออร์เดอร์
- แก้ข้อมูลจัดส่งหลังสร้าง: หน้ารายละเอียดออร์เดอร์ → "แก้ข้อมูลจัดส่ง" (ก่อนส่งมอบ/ยกเลิก) ยอด/VAT คิดใหม่ + บันทึกประวัติ
- ความเป็นส่วนตัว: หน้าลิงก์ออร์เดอร์แสดงแค่ชื่อสถานที่ ระยะทาง ค่าส่ง (ไม่แสดงที่อยู่/url/รายละเอียด) · เจ้าของที่ล็อกอินเห็นเต็ม
