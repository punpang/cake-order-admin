# เช็กลิสต์ทดสอบบนอุปกรณ์จริง

ทีมทดสอบทำบนเครื่องจริงก่อนเปิดใช้งานเต็มรูปแบบ บันทึกผลเป็น ผ่าน / ไม่ผ่าน พร้อมรุ่นเครื่องและเวอร์ชันเบราว์เซอร์หรือแอป

## ทุกเครื่อง
- [ ] รับเงินสดที่ POS แล้วใบเสร็จออกถูกต้อง และสถานะเปลี่ยนเป็นบันทึกแล้วหลังซิงก์
- [ ] ปิดหรือรีเฟรชแท็บขณะมีรายการยังไม่บันทึก → เบราว์เซอร์เตือน และรายการถูกส่งทันที
- [ ] ออร์เดอร์ที่ถูกปฏิเสธ (เช่น ยอดเกินบิล) แสดงสถานะล้มเหลวและข้อความให้แก้ไข ไม่หายเงียบ
- [ ] ยกเลิกออร์เดอร์ค้างที่ไม่มีการเงิน → หายจากเครื่องและไม่ค้างสถานะล้มเหลว
- [ ] ยกเลิกออร์เดอร์ค้างที่มีรายการรับเงิน → ยังค้างให้เห็น ไม่หายเงียบ
- [ ] ช่องกรอกตัวเลขและเบอร์โทรบนมือถือไม่ซูมอัตโนมัติ (ตัวอักษรอย่างน้อย 16px)

## iPhone / iPad (Safari)
- [ ] สลับไปแอปอื่นขณะมีรายการรอ → กลับมาแล้วรายการถูกบันทึกขึ้นเซิร์ฟเวอร์
- [ ] ปิดแท็บด้วยการปัดแอปทิ้งหลังบันทึกรายการแล้ว → รายการที่บันทึกไปแล้วไม่หาย
- [ ] พิมพ์ใบเสร็จผ่าน window.print ความกว้างกระดาษ 58 หรือ 80 มม. ตรงกับที่ตั้งค่า
- [ ] หน้าชำระเงินบน iPad แนวนอนและแนวตั้งไม่เลื่อนเกินหน้าจอ

## Android (แอปและ Chrome)
- [ ] จับคู่เครื่องพิมพ์ Bluetooth (SPP) และพิมพ์ใบเสร็จ 58 มม. และ 80 มม. ตามตั้งค่า
- [ ] พิมพ์หลายงานติดกันไม่สลับลำดับ (คิวทีละงาน)
- [ ] จำนวนชุดตามตั้งค่า ชุดที่ 2 ขึ้นไปไม่พิมพ์ QR ลุ้นโชค
- [ ] สลับแอปขณะมีรายการรอ → กลับมาแล้วบันทึกสำเร็จ
- [ ] ใบกำกับภาษี A4 บน Chrome เปิดกล่องพิมพ์ของเบราว์เซอร์ได้
