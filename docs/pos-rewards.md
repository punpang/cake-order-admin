# POS: คูปอง & ของรางวัล

ลูกค้าต้องกด **"ใช้ที่ร้านตอนนี้"** ในระบบลูกค้าก่อน รายการจึงขึ้นบน POS (ยืนยันว่าลูกค้าทำรายการเอง) — ดูวงจรเต็มที่ [loyalty-coupons.md](loyalty-coupons.md)

- **คูปองส่วนลด**: ขึ้นในขั้นตอนชำระเงินเฉพาะที่ลูกค้ากดแสดงอยู่ (มีนับถอยหลัง) · ถ้ามีแต่ยังไม่กด POS บอกให้ลูกค้ากดเอง · `posSale` ตรวจซ้ำฝั่ง store (ไม่ active/ของคนอื่น/หมดเวลา = ไม่ขาย)
- **ปุ่ม "มอบของรางวัล"** (สิทธิ์ `useLoyalty`): ค้นหาลูกค้าก่อน → แสดงของรางวัลที่ลูกค้ากดแสดงอยู่ → "มอบของ" = ใช้แล้ว หายจากจอ · ไม่มี "แลกและมอบ" ด้วยคะแนนที่ POS แล้ว · ต้นทุนของรางวัล (5430) ลงบัญชีตอนมอบ
- **ลบรายการในตะกร้า**: ปุ่ม − บนการ์ดสินค้า · ✕ บนแถบสรุปมือถือ · ถังขยะต่อบรรทัด · ล้างตะกร้า (ถามยืนยัน) · ปัดซ้ายที่บรรทัด · ทุกแบบเลิกทำได้ 5 วินาที
