# POS: คูปอง & แลกของรางวัล

- **คูปองส่วนลดของสมาชิก** แสดงในขั้นตอนชำระเงินให้กดใช้แทนเงินสด (ขั้นต่ำไม่ถึง = ปุ่มปิด + เหตุผล) แผงสมาชิกบอกจำนวนคูปองเท่านั้น
- **ปุ่ม "แลกของรางวัล"** (สิทธิ์ `useLoyalty`): ต้องค้นหาลูกค้าก่อนจึงแสดง (1) ของที่แลก/ได้จากกาชาไว้แล้วและรอรับ → ปุ่ม "มอบของ" (2) รายการแลกด้วยคะแนน → "แลกและมอบ" (ตัดคะแนน + มอบทันที) · บัญชีลงต้นทุนของรางวัล (5430) ตอนมอบอัตโนมัติ
