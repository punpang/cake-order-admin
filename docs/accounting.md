# ระบบบัญชี (รอบ M · แกน) — ฐานสิทธิ ลงบัญชีคู่

หน้า `/admin/accounting` (สิทธิ์ `acctView`) แท็บ: ภาพรวม · บันทึก · สมุดรายวัน · รายงาน · ผังบัญชี · ปิดงวด/ตั้งค่า

- **ดึงอัตโนมัติ** (`src/lib/acct/derive.js`, คำนวณจากสถานะปัจจุบันของออร์เดอร์ ไม่ต้อง hook): รับชำระแต่ละงวด → เงินสด/ธนาคารเดบิต · รายได้รับล่วงหน้า (2300) + ภาษีขาย (2200) เครดิต · ส่งมอบ → รับรู้รายได้ (4100/4200/4300) + ต้นทุนขายตามสูตร (5100/1200) + ค่าคะแนน (5410) / ส่วนลดคูปอง (5420) · ยกเลิก → กลับรายการ + คืนเงินตามช่องทาง (คืนเป็นคะแนน = ภาระ 2310) + ริบมัดจำเป็นรายได้อื่น (4900) · ของรางวัลที่มอบ (5430)
- **บันทึกเอง**: รายได้/ค่าใช้จ่าย (VAT ไม่มี/รวม/ไม่รวม, ขอคืนภาษีซื้อ, เงินสด/ธนาคาร/ค้างจ่าย-ค้างรับ, แนบรูป) หรือรายการบัญชีขั้นสูง · เลขที่ `JV-<ปี พ.ศ.>-0001` · แก้/ลบได้ก่อนปิดงวด · ค้างจ่าย/ค้างรับ ชำระภายหลังได้
- **ปิดงวด**: แช่แข็งรายการอัตโนมัติถึงวันที่เลือก (แก้ออร์เดอร์ย้อนหลังไม่เปลี่ยนตัวเลข) · บันทึกเองถึงวันนั้นแก้ไม่ได้ ต้อง "กลับรายการ" · เปิดงวดกลับต้องมีสิทธิ์ `acctClose`
- **รายงาน**: งบทดลอง · งบกำไรขาดทุน · บัญชีแยกประเภท (งบการเงินอื่น/เปรียบเทียบ/ภาษีอยู่ในรอบถัดไป)
- เงินคำนวณเป็นสตางค์จำนวนเต็ม ทุกรายการต้องเดบิต = เครดิต
- ผังบัญชีแก้ได้ (บัญชีที่ระบบใช้ปิด/ลบไม่ได้) · โหมดจำลองในหน่วยความจำ ยังไม่ต่อ Supabase
