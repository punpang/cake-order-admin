# ใบกำกับภาษีเต็มรูปของสั่งล่วงหน้า (เฟส 4) — design

## เจตนา
ออกใบกำกับภาษีเต็มรูปให้ออร์เดอร์สั่งล่วงหน้าที่ **ส่งมอบแล้วและชำระครบ** โดยพนักงานกดออกจากหน้าออร์เดอร์
ใบที่ออกใช้เลขที่และรูปแบบเดียวกับใบของออร์เดอร์ปกติ (เลขต่อเนื่องจาก trigger เดิม)

## ขอบเขต
- **อยู่ในรอบนี้:** ฟังก์ชันตรรกะ (ตรวจสิทธิ์ออก), RPC ฐานข้อมูลสำหรับบันทึกใบ, action `issue_invoice` ใน `preorder-admin`, เทสต์
- **ไม่อยู่ในรอบนี้:** หน้าพนักงานกรอกข้อมูลผู้ซื้อและกดออกใบ (UI ตามมาในรอบถัดไป) · ให้ลูกค้าขอใบเองจากหน้าสั่งล่วงหน้า · การแก้/ยกเลิกใบหลังออก (ใช้กระบวนการเดิมหลังบ้าน)

## แนวทางที่เลือก
- **A (เลือก):** พนักงานออกใบจากหน้าออร์เดอร์หลังส่งมอบและชำระครบ ผ่าน action ใหม่ใน `preorder-admin`
- B (ไม่เลือก): ขยาย `tax-invoice` ให้ลูกค้าขอเอง — ต้องแก้ RPC และกติกาช่วงเวลา เสี่ยงสูงกว่า
- C (ไม่เลือก): ออกอัตโนมัติตอนส่งมอบ — ถ้าข้อมูลผู้ซื้อไม่ครบจะออกไม่ได้และแก้ยาก

## กติกาการออกใบ (ตัดสินที่เซิร์ฟเวอร์)
1. สถานะออร์เดอร์ = `delivered`
2. ออร์เดอร์มี VAT (`vat.rate > 0`)
3. ยอดค้างชำระ (`orderTotals(order).balance`) ≤ 0.004 บาท
4. ข้อมูลร้าน (ตั้งค่า → VAT) พร้อม (`sellerCheck`)
5. ข้อมูลผู้ซื้อถูกต้อง (`buyerError` ว่าง)
6. ยังไม่มีใบกำกับที่ไม่ถูกยกเลิกของออร์เดอร์นี้
7. วันที่ใบ = วันนี้ตามเวลาไทย · ไม่มีกรอบเวลาให้ลูกค้า (เป็นการออกโดยพนักงาน)

ข้อผิดพลาดแต่ละข้อส่งกลับเป็นข้อความภาษาไทยที่แสดงให้พนักงานได้

## ส่วนประกอบ
- `src/lib/preorderInvoice.js` (ฟังก์ชันล้วน): `preorderInvoiceBlock(order, invoices, buyer, seller, todayStr)` คืน `''` เมื่อออกได้ หรือข้อความ · ใช้ `buildInvoice` เดิมจาก `taxInvoice.js` สร้างใบ
- migration `supabase/migrations/20261126370000_punpang_preorder_invoice.sql`: RPC `punpang_preorder_issue_invoice(p_order text, p_date date, p_inv_id text, p_inv_data jsonb)` — ล็อกแถวออร์เดอร์, ตรวจสถานะและใบซ้ำในธุรกรรมเดียว, แทรกใบ (เลขโดย trigger เดิม), คืน `{ no }` · สิทธิ์เฉพาะ `service_role`
- `supabase/functions/preorder-admin/index.ts`: action `issue_invoice` รับ `orderId`, `buyer`, สร้างใบ, เรียก RPC · สิทธิ์เดิม (`managePreorder` หรือ `manage`)
- `scripts/sync-schedlib.mjs`: เพิ่ม `preorderInvoice.js` ให้ Edge Function ใช้กติกาชุดเดียวกับแอป

## สิ่งที่ผู้สร้างตัดสินเอง (ไม่กระทบสิ่งที่สร้าง)
- ชื่อ action = `issue_invoice`, ชื่อ RPC = `punpang_preorder_issue_invoice`
- ไม่บันทึกข้อมูลผู้ซื้อลงลูกค้า (`rememberTax`) ในรอบนี้
- ใบออกภายใต้ `by = 'staff:<user id>'` เพื่อตรวจย้อนหลังได้
