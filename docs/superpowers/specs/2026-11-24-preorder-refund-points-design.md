# คืนเงินออร์เดอร์สั่งล่วงหน้าเป็นคะแนน (ออกแบบ)

**เหตุผล:** ร้านต้องการให้ยกเลิกออร์เดอร์สั่งล่วงหน้าคืนเป็นคะแนนได้ นอกจากเงินสดและโอน

**เป้าหมาย:** ร้านเลือกวิธี `points` ในลิสต์การคืนเงินตอนยกเลิกได้ ลูกค้าได้คะแนนใหม่ในบัญชี บัญชีบันทึกหนี้สินคะแนน (2310)

**ไม่ทำ:** คืนเป็นคูปอง · วันหมดอายุของคะแนนที่คืน (อนุมัติแล้ว: ไม่มีวันหมดอายุ)

**วิธีทำ**
- ลิสต์การคืนรับ `cash` `bank` `points`
- คะแนนที่คืน = ยอดคืน ÷ `pointValue` ต้องเป็นจำนวนเต็ม ไม่งั้นปฏิเสธ
- เพิ่มก้อนคะแนนใหม่ในลิสต์แต้มของลูกค้า (รูปแบบเดียวกับก้อนที่ได้จากการสั่งซื้อ) มี `expiresAt` เป็น null และ `orderId` ของออร์เดอร์
- บัญชี: ยอดคืนเป็นคะแนนลงเครดิต 2310 แทนเงินออก · ส่วนที่เหลือเป็นริบเข้า 4900 ตามเดิม

**ความเสี่ยง:** หนี้สินคะแนนของร้านจะไม่ลดลงเองเพราะไม่มีวันหมดอายุ

**การทดสอบ:** SQL (คืนเป็นคะแนนสำเร็จ ยอดไม่หาร pointValue ถูกปฏิเสธ ก้อนที่สร้างไม่มีวันหมดอายุ) · บัญชี (คืนเป็นคะแนนลงเครดิต 2310)
