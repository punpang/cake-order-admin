# คืนเงินบางส่วน (ไม่ยกเลิกออร์เดอร์/บิล)

ปุ่ม "คืนเงิน" ที่การ์ด "การชำระเงิน" ของ `admin/orders/:id` และที่แถวบิลในแท็บ "บิล" ของ POS → โมดัล `RefundPartialDialog.vue` (ใช้ `RefundEditor` เดิม: เงินสด / ธนาคาร(โอน) / คะแนนสะสม แบ่งหลายช่องทางได้)

- ข้อมูล: `order.returns = [{ id, at, by, reason, note, refunds:[{method,amount,points?}], amount }]` · ฟังก์ชัน `refundOrder(order, { reason, refunds, note, notify })` ใน `store.js` (ตรวจครบก่อนแก้ข้อมูล)
- เพดาน: รวมทุกครั้งไม่เกิน `paidNet = paid − returned` (`orderTotals`) · ยกเลิกออร์เดอร์/บิลภายหลังใช้เพดานเดียวกัน (ไม่คืนซ้ำ) · เหตุผลบังคับ
- `balance` (ยอดค้าง) ไม่เปลี่ยน — ถือเป็นการชดเชย ไม่ใช่ให้ลูกค้าจ่ายเพิ่ม · ไม่ย้อนสต็อก/คะแนนที่ได้จากการซื้อ (เฉพาะตอนยกเลิก)
- คืนเป็นคะแนน = ยอด ÷ มูลค่าต่อคะแนน (ต้องหารลงตัว) ต้องมีลูกค้า
- ยกเลิกยอดที่ยืนยันแล้ว (`cancelConfirmedPayment`) ทำไม่ได้ถ้าจะทำให้ชำระสุทธิติดลบ
- สิทธิ์: ออร์เดอร์ `refundPartial` (ค่าเริ่มต้น admin) · บิล POS `posVoid`
- แจ้งลูกค้า (ออร์เดอร์เว็บเท่านั้น): เหตุการณ์ `order_refunded` (ติ๊กในโมดัล) · หน้าลูกค้าแสดงรายการ "คืนเงินบางส่วน"
- POS กะ: `shiftSummary` หักเงินสดที่คืนออกจากเงินสด, โอนที่คืนหักจากช่องทางไม่ใช่เงินสดของบิลนั้น, คะแนนไม่กระทบลิ้นชัก

## บัญชี (`lib/acct/derive.js`)
รายการ `ret:<order>:<return>`: Dr `4950` คืนเงิน/ส่วนลดหลังขาย (หักรายได้ contra) + Dr ภาษีขายส่วนที่คืน / Cr เงินสด | ธนาคาร | หนี้คะแนน (`2310`) · ใช้ได้ทั้งก่อน/หลังส่งมอบ · ถ้ายกเลิกทีหลัง รายการยกเลิกกลับ 4950 และไม่นับเป็นเงินมัดจำที่ริบ
**ยังไม่ออกใบลดหนี้อัตโนมัติ** สำหรับการคืนบางส่วน (โมดัลเตือนเมื่อออกใบกำกับแล้ว) — ยกเลิกทั้งใบจึงออก

## ยกเลิกการคืนเงิน (รอบ AN)
- ยกเลิกได้ทุกรายการที่คืนไว้ (`cancelRefund(order, returnId, { reason, notify })` ใน `store.js`) · สิทธิ์เดียวกับการคืน (ออร์เดอร์ `refundPartial` · POS `posVoid`) · ต้องใส่เหตุผล
- ไม่ลบรายการ: เก็บ `entry.cancelled = { at, by, reason }` แสดงขีดฆ่า + ป้าย "ยกเลิกแล้ว" · `returnsOf`/`returned`/`paidNet`/สรุปกะ POS นับเฉพาะที่ยังไม่ยกเลิก (`allReturnsOf` = ทั้งหมดไว้แสดงประวัติ)
- ปฏิเสธเมื่อ: ออร์เดอร์/บิลถูกยกเลิก · วันที่คืนอยู่ในงวดบัญชีที่ปิดแล้ว · เดือนภาษียื่น ภ.พ.30 แล้ว (มี VAT) · คืนเป็นคะแนนแล้วลูกค้าใช้คะแนนก้อนนั้นไปแล้ว (ตรวจก่อนแก้ข้อมูล ไม่ยกเลิกครึ่งเดียว)
- คะแนน: หักคะแนนที่คืนให้กลับ (ก้อนที่คืนเก็บ `lotId`; ข้อมูลเก่าหาจาก ledger)
- บัญชี: `ret:` เดิม + `retx:` กลับรายการลงวันที่ยกเลิก (4950 สุทธิ 0, งบทดลองสมดุล)
- แจ้งลูกค้า: ช่องติ๊กใน `RefundCancelDialog.vue` ค่าเริ่มต้น**ไม่แจ้ง** (ไม่มีใน POS) · เหตุการณ์ `order_refund_cancelled` (ข้อความ + กระดิ่งลูกค้า)
- UI: ปุ่ม "ยกเลิกการคืน" ในรายการ "คืนเงินแล้ว" ของหน้ารายละเอียดออร์เดอร์ และในโมดัลคืนเงินของ POS (ปุ่ม "คืนเงิน" ของบิลยังเปิดได้แม้คืนครบแล้ว)
