# วงจรคูปอง/ของรางวัล

สถานะ (คำนวณจาก `couponPhase` ใน `src/lib/loyalty.js`): `pending` ยังไม่ใช้ → `active` ลูกค้ากด "ใช้ที่ร้านตอนนี้" (POS เห็น `activationMin` นาที, ตั้งได้ 1–120, ค่าเริ่มต้น 15) → `delivered`/`used` พนักงานมอบ/ใช้ที่ POS · `lapsed` ครบเวลาโดยไม่ได้มอบ/ใช้ = **ถือว่าใช้ไปแล้ว** (ใช้ซ้ำไม่ได้) · `refunded` หลังบ้านคืนคะแนน · `expired` หมดอายุตามวันที่

- ลูกค้ายกเลิกคูปองที่แลกแล้วเองไม่ได้ · ครบเวลาไม่ได้คืนคะแนนอัตโนมัติ
- ยกเลิกบิล POS ที่ใช้คูปอง → คูปองกลับเป็น `pending` (ลูกค้าต้องกดใหม่)
- `sweepCoupons()` ตั้ง `lapsed` ถาวร (ทำตามรอบตรวจ + ตอนทำรายการ)
- **คืนคะแนน** (หลังบ้าน จัดการ → คะแนน & รางวัล → คูปอง & มอบของ · สิทธิ์ `adjustPoints` · ต้องมีเหตุผล): ได้กับ pending/active/lapsed/expired · คืนเท่าที่จ่าย (`coupon.points`, คูปองเก่าคำนวณจากตั้งค่าของแลก) · ของจากกาชาไม่มีคะแนนให้คืน · คืนซ้ำไม่ได้ · ติ๊กแจ้งลูกค้าได้ (ค่าเริ่มต้นส่ง)
- แจ้งทีม: `team_coupon_shown` เมื่อลูกค้ากดแสดง · แจ้งลูกค้า: `coupon_refunded`
- หลังบ้านมอบของรางวัลได้โดยไม่ต้องรอลูกค้ากด (สำหรับแอดมิน)
