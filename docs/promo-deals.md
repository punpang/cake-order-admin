# ดีลโปรโมชัน (POS + ออร์เดอร์)

หลังบ้าน: จัดการ → โปรโมชัน → แท็บ "ดีล" · ข้อมูล `db.posDeals` · คำนวณใน `applyPosPromos` (`src/lib/posPromo.js`) · คำอธิบาย/คำเตือน `src/lib/promoDeals.js`

| kind | ความหมาย | ฟิลด์ |
|---|---|---|
| `bogo` | ซื้อ X แถม Y (ชิ้นเดียวกันหรือสินค้าอื่น) | scope/itemIds/categories, buyQty, giftQty, giftItemId, repeat, maxGifts |
| `nth` | ชิ้นที่ N ลด % (ซื้อ 3 จ่าย 2 = n3/100%) — ชิ้นถูกสุดในกลุ่มลด | scope…, n, percent |
| `spend_off` | ซื้อครบ X ลด Y แบบขั้นบันได (บาท/%) ใช้ขั้นสูงสุดที่ถึง | tiers[{min,type,value}] |
| `spend_free` | ซื้อครบ X ฟรีสินค้า | min, giftItemId, giftQty |
| `spend_addon` | ซื้อครบ X ซื้อสินค้า Z ราคาพิเศษ | min, itemId, price, limit |
| `free_ship` | ส่งฟรีเมื่อครบ X (ออร์เดอร์จัดส่ง) | min |

## กติกา
- ยอดเทียบ `min` = ยอดสินค้าก่อนโปรรายชิ้น (รวมเค้กสั่งทำในออร์เดอร์) ไม่นับของแถม ค่าส่ง และ VAT
- สินค้า 1 ชิ้นใช้ได้โปรรายชิ้นเดียว (ส่วนลด/บันเดิ้ล/ชิ้นที่ N/add-on อันที่ลดมากสุด) · ดีลตามยอด (ครบลด) เทียบกับส่วนลดท้ายบิลเดิม เอาอันที่ลดมากสุด · ของแถมและส่งฟรีซ้อนได้
- ของแถม = แถวราคา 0 (`promoGift`, ส่วนลดชนิด `gift`) · สต็อกไม่พอ/หมด → แถมเท่าที่มี/ไม่แถม + hint · POS ตัดสต็อกของแถมด้วย (ยกเลิกบิลคืนให้) · ออร์เดอร์ไม่ตัดสต็อกสินค้าสำเร็จอยู่แล้ว
- ออร์เดอร์: `withPromos(items)` ใช้ที่ `createOrder` / `repriceAll` / `sendQuote` · เค้กสั่งทำนับยอดและรับส่วนลดตามยอด (ไม่ติดโปรรายสินค้า) · ส่วนลดเฉลี่ยต่อชิ้นไม่แยกรายการ · `order.promoOn` = ออร์เดอร์ที่เปิดคิดโปร (ออร์เดอร์เก่าไม่ถูกคิดโปรย้อนหลัง) · `order.shipPromo = { name, free }` → `orderTotals` ค่าส่ง 0 + บรรทัด "ส่งฟรี"
- hint ("ซื้ออีก 1 ชิ้น แถม 1", "อีก ฿120 ลดเพิ่ม") แสดงในตะกร้า POS และขั้นสินค้าของหน้าสร้างออร์เดอร์
