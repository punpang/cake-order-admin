# วัน-เวลาปิดร้าน + บอทแจ้งร้านปิด (รอบ J)

- ตั้งค่าร้าน → "วัน-เวลาปิดร้าน": ปิดประจำสัปดาห์ (เช่น ทุกวันอังคาร) · ปิดวันที่เจาะจง/ช่วงวัน (หยุดยาว + เหตุผล) · ปิดบางช่วงเวลาในวัน (เช่น 12:00–13:00 ทุกวัน หรือเฉพาะบางวัน) · ช่วงเวลาปิดข้ามเที่ยงคืนไม่รองรับ (ใช้ช่วงวันแทน) · ตั้งได้ไม่เกิน 100 รายการต่อประเภท
- วัน-เวลานัดรับ/ส่งที่ตรงช่วงปิดเลือกไม่ได้ (ช่องเวลาขีดฆ่า + เหตุผล / วันปิดทั้งวันแจ้งเตือน) · store ตรวจซ้ำตอนสร้างออร์เดอร์/ร่าง แก้วันนัด ส่งใบเสนอ และตอนลูกค้ายืนยันใบเสนอ · แชทและสั่งวัน-เวลาที่ไม่ปิดทำได้ปกติ
- บอท (ต้องเปิดบอทและช่องทางนั้น): ข้อความแรกของวันของแชทนั้นที่ทักมาตอนร้านปิด (ปิดทั้งวัน / ช่วงเวลาปิด / นอกเวลาเปิด-ปิดประจำวัน) → ส่ง `ข้อความแจ้งร้านปิด` (ตัวแปร {เหตุผล} {เปิดอีกครั้ง}) แล้วตอบเรื่องอื่นต่อตามปกติ · แจ้งครั้งเดียวต่อวันต่อแชท · โหมดตอบเอง = ส่งทันที · โหมดแนะนำ = แนบเป็น "ส่งก่อน" ในร่างให้พนักงานกดส่ง · ถ้าทักครั้งแรกของวันตอนร้านเปิด แล้วมาทักใหม่ตอนปิด จะไม่แจ้ง
- ข้อความ "นอกเวลาทำการ" เดิมยังเป็นคำตอบสำรองท้ายสาย
