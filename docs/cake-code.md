# เลือกเค้กสั่งทำบนหน้าเว็บ + รหัสคัดลอก (รอบ H)

- หน้าเมนูเค้กสั่งทำ (`#/menu/custom/<ประเภท>`) มี "เลือกแบบ · ดูราคาเบื้องต้น": ลูกค้าเลือกเนื้อ/ขนาด/ตัวเลือกเสริม/ข้อความบนเค้ก/จำนวน (เค้กชั้นได้) ราคาคิดด้วยตัวคิดราคาเดียวกับหลังบ้าน (`priceDetail`) และตัวเลือกที่ประเภทนั้นใช้ไม่ได้จะไม่แสดง
- ปุ่ม "คัดลอกส่งร้าน" ได้ข้อความสั้น: บรรทัดสรุป (ชื่อ × จำนวน = ยอด) + ตัวเลือกเพิ่มเติม + รหัสบรรทัดสุดท้าย `#CK1.<payload>.<checksum>` (2 ชั้นเต็มยศ ≈ 300 ตัวอักษร)
- หลังบ้านรับรหัส 2 ทาง: (1) ช่อง "วางข้อความ/รหัสที่ลูกค้าคัดลอกมา" ใน "เพิ่มสินค้า" (สร้างออร์เดอร์/แก้ออร์เดอร์) (2) แชท: ข้อความลูกค้าที่มีรหัสจะมีปุ่ม "เพิ่มเค้กนี้ลงร่างออร์เดอร์"
- ตรวจตอนวาง: checksum · เวอร์ชัน · กลุ่ม/ตัวเลือกต้องยังมีและเปิดใช้ · ตัวเลือกต้องใช้กับประเภทได้ · จำนวน/ชั้น/ความยาวข้อความ · ถ้าราคาร้านเปลี่ยนจากที่ลูกค้าเห็น แสดงทั้งสองยอดและใช้ราคาปัจจุบัน · ถ้ามีตัวเลือกถูกลบ/ปิด จะปฏิเสธพร้อมเหตุผล (ไม่เดาแทน)
- ลิงก์ "หลังบ้าน" ถูกถอดจากหน้าลูกค้าแล้ว (เข้าด้วย `/#/admin` และต้องเป็นพนักงาน)
