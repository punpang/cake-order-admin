# แผนเฟส 2: สิทธิประโยชน์ระดับสมาชิก (ฉบับร่าง · ยังไม่เขียนโค้ด)

สถานะ: เฟส 1 อยู่บน main แล้ว และ `config/memberLevels` บน production เป็น `live` ตั้งแต่ 2026-11-23 02:39 UTC (ตามคำสั่งผู้ใช้ คงไว้)
ขอบเขตจาก `docs/loyalty-tiers.md`: สิทธิประโยชน์ตามระดับ (แต้มต้อนรับ คูปอง ตัวคูณเดือนเกิด) · โหมดคูปองใหม่ (ส่วนลดค่าส่ง, ลด % เฉพาะเค้ก) · เก็บวันเกิดสมาชิก

## ลำดับที่เสนอ
1. ผู้ใช้ตอบคำถามด้านล่าง
2. ร่างกฎและตัวเลขเริ่มต้นเป็นเอกสาร แล้วให้ผู้ใช้อนุมัติ
3. เขียน migration และโค้ดบนสาขา dev ปิดด้วยค่าเริ่มต้น `off`
4. ทดสอบ (unit, db, e2e) แล้วขอ Release แยก

## ต้องให้ผู้ใช้ตัดสิน
1. สิทธิแต่ละระดับ (LV1–LV4): แต้มต้อนรับเท่าไร คูปองอะไร มูลค่าเท่าไร
2. เดือนเกิด: ให้อะไร (ส่วนลด หรือของแถม) และให้ตอนไหนของเดือน
3. โหมดคูปองใหม่: ส่วนลดค่าส่งกี่บาท และลด % เฉพาะเค้กกี่ %
4. คูปองซ้อนกับตัวคูณแต้มได้ไหม และซ้อนกับคูปองเดิมของร้านได้ไหม
5. เก็บวันเกิดสมาชิก: ต้องแก้ประกาศความเป็นส่วนตัว (PDPA) ก่อนเก็บ และต้องมีผู้ยืนยันถ้อยคำ

## ข้อกำหนดก่อนเริ่ม
- ประกาศความเป็นส่วนตัวหัวข้อวันเกิดต้องยืนยันก่อนเก็บข้อมูล
- ถ้อยคำ ManageLegal หัวข้อ 8 ยังรอผู้ยืนยัน (ดู `docs/loyalty-tiers.md`)
- การเปลี่ยน schema หรือ config ทุกครั้งต้องขอ Release แยกและอนุมัติก่อน
